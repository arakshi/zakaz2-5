# ВКР-приложение: маркетинговая аналитика e-commerce

Готовое Streamlit-приложение для аналитической обработки маркетинговых данных ООО «Фабрика универсальных покрытий».

## Запуск в PyCharm (одной кнопкой Run)
1. Откройте проект в PyCharm.
2. Выберите интерпретатор Python 3.11+.
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Откройте файл `main.py`.
5. Нажмите **Run** (зелёная кнопка).
6. Откройте URL из консоли (обычно `http://localhost:8501`).

> Важно: запускать нужно `main.py`, а не вручную `streamlit run ...`.

## Быстрый запуск из терминала (опционально)
```bash
python main.py
```

По умолчанию используется SQLite (`data/app.db`). База создаётся автоматически при первом запуске.

## Опционально PostgreSQL
Установите переменную среды:
```bash
APP_DB_URL=postgresql+psycopg2://user:password@localhost:5432/marketing
```

## Структура
- `core/` — метрики, прогноз, инсайты, демо-данные, конфиг.
- `ui/` — страницы и компоненты интерфейса.
- `connectors/` — коннекторы (demo mock).
- `storage/` — SQLAlchemy и репозиторий.
- `reports/` — HTML-отчеты.
- `tests/` — unit-тесты.


## Новые возможности по данным
- Ручной ввод продаж/трафика через форму в разделе **Интеграции**.
- Импорт существующей SQLite-базы (`.db/.sqlite`) вручную через кнопку **Импортировать базу**.
- Расширенные прогнозы: линейный, полиномиальный, скользящее среднее + доверительный диапазон.
- Переключатель светлой/тёмной темы убран: используется единый современный стиль интерфейса.
